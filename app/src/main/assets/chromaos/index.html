ChromaOS Release Notes

v2.1.0 Stable

Release Date: November 2026 • Official Build

System Specifications
App Name: ChromaOS
Version: 2.1.0 (Build 2)
Min Android Version: Android 7.0+ (API 24)
Target Platform: Android 10 - 16 (API 36)
Architecture: Native Broadcast + Kotlin
Theme System: Obsidian Dark (Human-Centred)

New Features

1. Real-Time Battery Indicator Widget

Direct native Android broadcast receiver tracking battery percentage, charging state, charger type (AC/USB/Qi), temperature, and health telemetry. Zero simulated or fake values.

2. Dynamic Bluetooth Device Indicator

Queries real connected audio devices, headsets, and peripherals. Completely hidden when no device is connected; automatically renders device name and status when connected.

3. Dark Human-Centred Design System

Sophisticated charcoal, graphite, deep grey, and muted warm stone tones. Eliminates neon glow clutter and generic AI dashboard aesthetic in favor of balanced commercial design.

Improvements & Optimizations

  • Event-driven architecture: Updates instantly on native broadcasts rather than expensive background polling loops.
  • Clean canvas default: Clean home screen canvas with widget hold-to-remove and intuitive catalog sheet.
  • Hardware-accelerated rendering: GPU-backed surface layers for 60fps/120fps transitions.
  • Automated reproducible release workflow configured with direct APK build output.

Bug Fixes

  • Removed legacy non-realtime battery widget and "Chroma High Resolution" placeholder cards.
  • Removed redundant "Download Runnable App" and "Save App" action buttons.
  • Properly isolated Bluetooth permissions for Android 10-11 (BLUETOOTH) and Android 12-16 (BLUETOOTH_CONNECT).
Known Limitations

Bluetooth accessory name resolution on Android 12+ requires runtime permission approval. Battery temperature precision depends on OEM hardware sensor capabilities.
